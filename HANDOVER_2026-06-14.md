## The dashboard (key for the next agent)

Lives in `dashboard/frontend/` (React 18 + Vite 5, deployed to Cloudflare Pages
via `.github/workflows/deploy.yml` job 3). Architecture after the Phase 1 refactor:

```
src/
  App.jsx                  thin shell: providers → socket → metrics → TopBar/TabBar → tabs
  theme/tokens.css         CSS variables (palette, rank-tier colors, keyframes)
  lib/constants.js         AGENTS, TYPE_CFG, RANK_META, fmt(), WS_URL
  lib/exp.js               frontend mirror of core/exp.py level math (KEEP IN SYNC)
  hooks/usePipelineSocket  WebSocket (live pipeline theatre + derived session state)
  hooks/useSupabaseRealtime feeds the TanStack Query cache from DB realtime
  hooks/useSupabaseData    cached reads + RPC hooks
  components/ui/           Panel, KpiRing, StatRow, Button, ExpBar
  components/AgentCard.jsx EXP card with quest-log flip
  components/charts/       EquityChart (recharts), EquityChartLW (lightweight-charts)
  panels/                  TopBar+TabBar, PipelinePanel, LivePanels (5 live panels)
  views/                   LiveView, PantheonView, PortfolioView, CostHealthView
```

**4 tabs:** LIVE (original view, WS-driven), PANTHEON (EXP/levels — the hero),
PORTFOLIO (equity curve, perf stats, R-multiples), COST & HEALTH (LLM spend,
health board).

**Two data planes (do not mix):**
- WebSocket (`dashboard/backend/server.py:8081`) = live pipeline theatre only.
- Supabase realtime (anon key) = all persisted history + EXP/seniority.

## The EXP system (cosmetic, never touches sizing)

- **GOLDEN RULE:** EXP is flair. The real-money gate stays
  `system_level.max_position_pct()` in `zeus.py`. Never let `exp_level` affect
  position sizing. (`core/exp.py` docstring + LESSONS state this.)
- Math: `core/exp.py` (pure functions, 20 tests in `tests/test_exp.py`).
  Frontend mirror: `dashboard/frontend/src/lib/exp.js` — **edit both together.**
- Minting:
  - Trade XP — `core/shadow_learning.py::OutcomeResolver._mint_trade_xp`
    (SELECTs the trade row back by order_id; idempotent on order_id).
  - Promotion +1000 jackpot — `agents/zeus.py::_award_promotion_xp` (idempotent
    on `promo:{agent}:{level}`).
- Storage: `agent_exp_ledger` (append-only, UNIQUE idempotency) → `agent_exp`
  (rollup the dashboard reads). Helpers in `core/supabase_client.py`.
